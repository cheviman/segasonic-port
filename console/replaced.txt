# The game's functions the console build puts its own in place of (console/*.c): tools/decompile.py writes
# their definitions as CONSOLE_ORIGINAL(name), which is original_name there and the game's own elsewhere.
attract_warning          # no licence screen: straight on to the title
advance_attract_screen   # the attract mode's screens in the console's order
draw_credit_count_now    # no "Free play" line: the console has no coins
blink_start_prompt       # no "Insert coin" without credits: the count beside it says 0
play_sound               # every sound and the music in the attract mode too
attract_title            # the title with music
run_frame_start_game     # a start button outside a game opens the menu (or goes back to the title)
run_game_mode            # the game the menu starts sees player 1's start, as the arcade's start frame does
character_chooser_wait   # player select: a touch of left or right turns at once
join_character_chooser_update # a continue's character chooser: a touch of left or right turns at once
game_mode_stage_select   # the stage select is the island map: a level a marker, every one open
draw_player_start_prompt # a player's start prompt is up: their start joins, it does not pause
system_mode_idle         # system mode 1 is the console's OPTIONS page
set_nbg0_scroll_from_camera # WIDE: the tile sets of the blocks from the wide left side on
place_message_box        # Eggman's lines and the how to play's captions: the game's own English boxes
how_to_play_button_hand_update # TRACKBALL: the how to play's hand presses the button as player 1 does
how_to_play_trackball_hand_update # TRACKBALL: its hand rubs the ball as player 1's turns; no captions, no scroll
